---
name: shell-out
description: Capture an explicitly authorized shell command's output privately with bounded previews and stable references; use manually for potentially large output.
---

Use the exported `shell-out` command manually. Authorization applies to the original command and all its effects. This wrapper grants no additional permissions. Never rely on a blanket allow rule for the wrapper, and do not install hooks or rewrite permission settings.

Pass explicit argv after `--`. For shell syntax, pass the intended shell and its script as separate argv elements, for example `shell-out run --cwd . -- bash -o pipefail -c 'printf "synthetic\n" | cat'`. Caller stdin is forwarded; use native redirection when needed. Environment inherits unless `--clear-env` is specified; repeat `--env NAME=value` for overrides. Avoid secrets in command-line options and session labels.

Small printable UTF-8 output, including tabs and a missing final newline, stays unchanged; large output has bounded head and tail. Binary output is summarized and controls are escaped. The final result on stderr contains the ref, private stream paths, command status, capture status, and observed/saved byte counts. Parse exactly one line-start literal ASCII 0x1e followed by `[shell-out result] ` and a single JSON object through EOF (trailing whitespace allowed); refuse missing, multiple or invalid frames. Child control bytes are escaped, so an ordinary child-printed marker is not a result. Presentation is best-effort with bounded queues and final flush deadlines; an undrained caller stream cannot block cancellation or cleanup, but can lose the frame. A preview is not the full output. Check `capture_status` before treating a log as complete. Investigate only needed ranges with grep, head, tail or sed; never copy captured output into reports, attachments, or task resources, or include private paths in commits or PRs.

Refs use `session/id`; `shell-out lookup --cwd . -- REF` returns their metadata. `shell-out purge --cwd .` explicitly removes expired completed captures and keeps tombstones. Discovery/lookup do not bootstrap directories, and purge does not create them. An existing project `.temp` must be a real directory owned by the effective user with no group or world write permission; accessible 0700, 0750 and 0755 parents are accepted unchanged. Normal OS access checks still apply; a missing `.temp` is created as 0700. Tool-owned `shell-out` and session directories must already be 0700, with new capture/metadata files 0600. Foreign-owned or symlinked directories and unsafe modes are refused; permissions are never repaired. Purge continues past corrupt metadata with warnings and exit 125; the reclaimed count is still printed. Torn/orphan files require operator inspection. Refs require the original absolute project/cache location; project relocation is unsupported. Default retention is 24 hours from completion. Run purge regularly; lookup expiry alone does not reclaim disk.

Git calls have a two-second deadline with bounded pipe drain. A mid-run rename can still finalize metadata through held directory handles; refs and stored paths retain their original location. A saturated or failed result-frame write preserves the child's nonzero exit or signal. Missing/truncated frames must still be refused; retained metadata contains the execution outcome, not proof that the frame was delivered.

Each call creates a subprocess with pipes. Shell-local cd/export state persists only within that invocation; it does not update the caller. No PTY is allocated, so colors, prompts, pagers and interactive programs may behave differently. Background processes in the command's process group are terminated when the main process ends. Programs that detach themselves can outlive this lifecycle; a pipe-drain deadline reports partial capture. See [README.md](README.md) for status, signal, retention, and packaging details.

Automatic runtime capture is unsupported in this MVP. A future adapter must refuse if it cannot preserve the original permission decision. The known-denied/nearby-allowed runtime integration test is pending a real seam, not satisfied by the manual command.
